Before you start

Install the Pukbot GitHub App on the repositories you want to manage. You also need an authenticated gh CLI.

macOS and Linux 
curl --proto '=https' --tlsv1.2 -fsSL https://gitbot.pulkit.page/install.sh | sh
Windows PowerShell 
irm https://gitbot.pulkit.page/install.ps1 | iex
Cargo 
cargo install pukbot --locked

One CLI, the useful GitHub operations.

Use direct commands interactively or typed JSON for repeatable automation.

Comments

Create, edit, delete, and react by comment ID. Bodies render full GitHub-flavored Markdown.

pukbot comment create 123 --repo owner/repo --body "ready"
pukbot comment edit 456 --repo owner/repo --body "updated"
pukbot comment delete 456 --repo owner/repo --yes

Markdown bodies

Pass multiline Markdown from a file or stdin, and preview the exact body before it is posted.

pukbot comment create 123 --repo owner/repo --body-file report.md
pukbot comment create 123 --repo owner/repo <report.md
pukbot apply --input request.json --dry-run

Images, video, and files

Place multiple named media items anywhere in a JSON comment body.

pukbot apply --input request.json
pukbot apply --input request.json --dry-run
pukbot apply --input request.json --json

Issues

Create and update issues, labels, assignees, state, and reactions.

pukbot issue create --repo owner/repo --title "bug"
pukbot issue labels 123 --repo owner/repo --add urgent
pukbot issue close 123 --repo owner/repo

Pull requests

Create, review, label, update, close, reopen, and squash merge, all authored by you rather than the App. 

pukbot pr review 123 --repo owner/repo --event approve
pukbot pr update-branch 123 --repo owner/repo
pukbot pr merge 123 --repo owner/repo --yes

Updates and completions

Keep the binary current and install completions for five shells.

pukbot update
pukbot update --check --json
pukbot completions --install

Discoverability

Generate manuals or inspect the machine-readable feature inventory.

pukbot man
pukbot man --dir ./man
pukbot capabilities --json

How it stays secure.

The local CLI coordinates the operation without handling App credentials.

1

Dispatch

The authenticated GitHub CLI dispatches a typed operation to Pukbot.

2

Authorize

A protected environment mints a short-lived token for one repository.

3

Expire

The operation completes, logs stream locally, and the token expires.

Your private key stays private.

It lives only in a protected GitHub Actions environment secret. It is never embedded in the CLI, crate, release binaries, Pages site, or installer scripts.
